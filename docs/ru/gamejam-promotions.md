# Промокоды для game jam

`cmd/gamejam-promotions` — самостоятельный сервис, который ищет российские и русскоязычные game jam, отправляет их на ручную модерацию и проверяет общие 10-значные промокоды. Он не импортирует gateway или Developer API и не использует control DB либо базы игровых модулей.

## Поиск и модерация

При старте и каждые шесть часов сервис проверяет «Геймдев Афишу», Jammer и itch.io. Доступ к источникам разрешён только по HTTPS, ограничен по времени и размеру и учитывает `robots.txt`. Ошибка источника фиксируется, но не удаляет и не активирует существующие данные.

Кандидат получает классификацию `likely_ru`, `unknown` или `unlikely_ru`. Классификация никогда не активирует промокод автоматически. Администратор открывает `/admin/`, исправляет нормализованные поля, выбирает основание `venue_ru`, `language_ru`, `audience_ru` или `organizer_ru` и подтверждает либо отклоняет событие. Несколько кандидатов из разных источников можно объединить в один game jam.

Одинаковый непустой официальный URL считается точным межисточниковым дублем: создать второй game jam нельзя, а админка предлагает существующее событие для merge. Совпадение нормализованного названия, дат и организатора отображается как необязательная подсказка о возможном дубле. Последующие изменения источника показываются как diff по полям и не переписывают одобренный снимок автоматически: модератор применяет обновление либо сохраняет текущий снимок и закрывает diff.

Админский listener рассчитан на TLS-хост `admin.ruleshift.ru`. Все пути, включая метрики и health-check, требуют HTTP Basic Auth. Пароль задаётся bcrypt-хешем.

## Коды и публичная проверка

При подтверждении создаётся один криптографически случайный 10-значный код. Ведущие нули значимы. Поиск выполняется через HMAC-SHA256, полный код хранится с шифрованием AES-256-GCM; оба ключа выводятся из `GAMEJAM_CODE_MASTER_KEY`. Master key должен оставаться стабильным и резервироваться вместе с PostgreSQL.

`POST /v1/gamejam-discounts/verify` принимает `{"code":"0123456789"}`. Код действует, только пока game jam подтверждён и текущая московская календарная дата входит во включительный диапазон события. Код общий, не погашается, число использований не хранится. Неизвестный и неактивный код дают одинаковый публичный ответ.

Полный контракт: [gamejam-promotions.openapi.yaml](../../api/gamejam-promotions.openapi.yaml). Сервис никогда не логирует введённые коды, URL источников, идентификаторы game jam или IP клиентов.

## Конфигурация

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `GAMEJAM_PUBLIC_ADDR` | `:8082` | Публичный listener проверки. |
| `GAMEJAM_ADMIN_ADDR` | `:9092` | Административный listener с Basic Auth. |
| `GAMEJAM_DATABASE_URL` | обязательно | Отдельная PostgreSQL-база `ruleshift_gamejam`. |
| `GAMEJAM_CODE_MASTER_KEY` | обязательно | Base64 ровно 32 стабильных случайных байт. |
| `GAMEJAM_ADMIN_USERNAME` | обязательно | Имя пользователя Basic Auth. |
| `GAMEJAM_ADMIN_PASSWORD_BCRYPT` | обязательно | Bcrypt-хеш пароля. |
| `GAMEJAM_ALLOWED_ORIGIN` | `https://ruleshift.ru` | Точный CORS origin сайта GitHub Pages на пользовательском домене. |
| `GAMEJAM_SYNC_INTERVAL` | `6h` | Период фонового поиска. |
| `GAMEJAM_SOURCE_USER_AGENT` | идентификатор Ruleshift | Контактный User-Agent для источников. |
| `GAMEJAM_AFISHA_URL` | `https://gamedev-afisha.ru/` | Переопределение источника «Афиша». |
| `GAMEJAM_JAMMER_URL` | `https://jammer.website/ru/jams` | Переопределение Jammer. |
| `GAMEJAM_ITCH_URL` | `https://itch.io/jams/upcoming` | Переопределение itch.io. |

Production-манифесты и шаблоны Secret/Ingress находятся в `deploy/k3s/gamejam-promotions`. Для production-сборки сайта требуется `VITE_GAMEJAM_API_URL`.
