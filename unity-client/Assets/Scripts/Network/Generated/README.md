# Generated Protobuf Files

Generated C# files from `internal/protocol/proto/ruleshift.proto` will live here after running:

```powershell
.\scripts\proto.ps1
```

Do not edit generated files by hand.

Unity must also have the Google.Protobuf runtime assembly available. Use the package/runtime version that matches the generated code style from `protoc`, and keep generated protocol files under the `Ruleshift.Protocol.V1` namespace.
